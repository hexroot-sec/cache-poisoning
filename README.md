# cache-poisoning

Extensão Chrome MV3 (Brave) que detecta Web Cache Poisoning de forma segura (cache-buster, reflexão/redirect/CPDoS, ESI). Educacional, uso autorizado.

## Uso
Carregue a pasta em `chrome://extensions` (modo desenvolvedor → "Carregar sem compactação"). Veja `PASSO_A_PASSO.md` (quando existir) e o `lab/` para testar localmente.

## Aviso legal
Use **somente** em alvos que você possui ou em programas de bug bounty/VDP com escopo autorizado, respeitando as regras do programa. Um alerta da ferramenta é um candidato, não uma vulnerabilidade confirmada: valide manualmente. Sem garantia; responsabilidade do usuário.
